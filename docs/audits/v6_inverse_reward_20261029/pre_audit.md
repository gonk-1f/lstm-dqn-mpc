# 修改前经济模型审计

2026-10-29；被审计生产基点 `814994e`。本报告形成前后生产源码均未修改，未启用新经济或奖励模式。数值来自冻结函数及本次明确标记的有界 Train 审计，不使用 Validation/Test 选择公式或参数。

## 结论与实施门禁

**不能直接启用严格倒数。** 35 条 Train 各 32 步的新合法固定策略前缀共 1120 个动作，出现 35 个 `C=0`，覆盖 27 个 Train ID，全部为正常非终止动作。不是只有合成边界才有零成本。若保留这些动作和费用定义，`1/C` 无定义；按用户的停止条件，经济/奖励生产改造暂停。

**没有证实旧物理方程错误或重复终端计费。** 旧 SOC 等效项是固定参考价值势差，而非本步真实氢气流。其充电抵扣可以超过当步实际氢气费用，说明不能把它解释成实际氢气分配，并不等于物理上凭空产生能量。固定势差在同 SOC 完整循环内抵消；实际账本与能量平衡仍按原公式执行。

## 1. 原公式、单位与调用链

`DirectVesselEnv.step` → `EconomicMPC.interval` → 电池 SOC、FC 损失、电池 weighted-Ah 与 `build_formal_interval_ledger`；随后 `onboard_reward_components` 添加 signed SOC 价值并选择训练奖励。`episode_metrics` 对同一真实 transition 的金额在线求和，Validation 也经同一 Direct 环境，不把训练回报反算成费用。

设 `dt_h=dt_s/3600`，电池母线功率 `P_b = P_load - P_fc`，放电为正：

```text
m_H2 = 0                                       if P_fc = 0
       P_fc * dt_h / (eta(P_fc) * LHV)          if P_fc > 0
C_H2 = 21.9 CNY/kg * m_H2

delta_E_cell = -P_b * dt_h / 0.95              discharge
              -P_b * dt_h * 0.95              charge (P_b < 0)
SOC_after = SOC_before + delta_E_cell / 624 kWh

C_SOCeq = (SOC_before-SOC_after) * 624
          * 21.9 / (eta_average * (120/3.6))
C = C_H2 + C_FCdeg + C_Battdeg + C_SOCeq
```

H2 是本步真实氢气费用，非负，FC 关闭时为零。FC/电池退化是已冻结寿命模型的累计损失差分费用，非负，停机/无吞吐或 EOL 截断后可能为零。SOC 项单位也是 CNY，但属于等效价值修正：放电为正、充电为负、SOC 不变为零。**C 不是四个必然正的真实现金支出相加，不能假设其严格为正。**

FC 账本：替换份额费用 `3500*600*.5=1050000 CNY`，累计电压损失 EOL 为 70000 μV；账单为 `1050000 * (clip(V_after/70000)-clip(V_before/70000))`。原始损失含启动事件、线性变载、按秒缩放的运行项；启动一次 358.65 CNY，关闭不再收第二次完整启动循环，但功率下降仍有变载项。EOL 后原始损失继续累计，费用封顶，没有自动更换。

电池账本：`I=P_b*1000/432 A`，`delta_Ah=abs(I)*dt_h`，乘 `1+3.25*(1-SOC)^2` 与既有电流应力项；按冻结 lifetime weighted-Ah 的 clipped 累计比例差乘 `2000*624 CNY`。这是吞吐退化模型，没有为了避免零成本新增日历老化或空转费用。SOC 已包含 .95，不能在 SOC 差再次重复乘除电池效率；历史发电成本方案中除以充电效率则是另一种明确的成本分配语义，见方案报告。

## 2. 实际 FC 曲线与固定平均值的目的

实际氢耗使用 `fuel_cell_efficiency.py` 中 source-backed PCHIP 曲线。原 100 kW 特征以相同负载率映射到 600 kW，效率百分数转为小数，实际耗氢不使用旧表 m_h2 列。来源工作簿、hash、A2:B12 与映射已写入原 evaluation identity，本次没有改曲线。

固定均值为 `math.fsum(eta(P) for P in range(10,601,10))/60 = 0.5711999752720877`，零功率点不参与。它是等权动作参考，不是当前航段能量加权效率或实际控制效率。

固定系数 `K=624*21.9/(eta_average*LHV)` 令 `C_SOCeq=K*(SOC_before-SOC_after)`，所以不管中间动作如何：`sum C_SOCeq=K*(SOC_initial-SOC_terminal)`。独立航段初始 SOC .6，没有岸电或额外末端补能；`evaluate_zhou_economics` 的首末 SOC 修正是该同一数值的评价表达，不会在训练或 episode_metrics 再叠一次。gamma=1、完整正常航段下，原纯经济回报等于完整费用负值；失败分数单列，不混入物理账本。

功率平衡使用 normalized 实际负载；原 deadband 把 [-1,0] 小负测量归零，正的小额负载不做本次新增阈值。无岸电 ONBOARD 任务没有其他能量源，充电母线能量来自 FC；没有凭空的岸电补给。物理方程严格满足 `P_fc+P_b=normalized_load`，本次所有新审计步的最大残差为 0。

## 3. 现有 Train 资料能证明什么

既有 8 轮逐航段 Train 汇总共 280 行，包含累计分项；47 组失败观察共 14241 稀疏行。后者缺中间动作及 FC/电池逐步退化 ledger，前者没有步内分布。**不能据此恢复全部 35 条历史完整轨迹的 C_t 分位数或 sum(1/C_t)。** 机器结果保留缺失值 null，没有拿 Val 轨迹补齐，也没有把航段均值当逐步样本。

为得到可复核逐步证据，另行生成 35×32=1120 个前缀步，以及最短 Train 的两个固定合法策略各 3272 步。策略是每步在原 Mask 内选最接近当前负载或 300 kW 的动作，没有修改 Mask、搜索超参数或学习网络。CSV 明确标为 `new_bounded_audit_execution_not_archived`；这些样本仅描述实际执行的动作，不覆盖全部合法动作或完整 35 条长航段。

数据来源、文件 SHA256、历史缺失清单在 [pre_audit.json](pre_audit.json) 的 archived_evidence 中；新轨迹逐步费用见 [train_prefix_steps.csv](train_prefix_steps.csv) 与 [train_full_steps.csv](train_full_steps.csv)。分位数采用 NumPy 默认线性插值；零/负按实际符号计，不使用 epsilon。逆值只对正成本作离线诊断，其缺失不是零奖励。

## 4. 物理合法边界与充电抵扣

fresh idle：SOC=.6、FC=0、load=0、battery=0、hold 动作合法，四项费用全为零；实际 Direct 环境可正常运行/完成，不能改判为物理失败。SOC=.2/.8 的 idle 也为零。

70 kW 高效充电例子用合法 60→70 kW 前序建立状态，再保持 70 kW、负载 0、母线充电 70 kW：`eta(70)=0.6385366677349289`。实际 H2 费 `0.020006681911183825`，固定 SOC 抵扣 `-0.02124693719430804`，比值 1.061992。fresh 当步 FCdeg=.042375，Battdeg≈.004183879392，总 C≈.045318624109，因此抵扣超出 H2 并不意味着 fresh 总成本为负。

构造 FC 与电池均 EOL 的同类模型边界时，两项 clipped 退化费用为零，总 C≈`-0.0012402552831242142`。原模型接受该边界，且它不改变物理可行动作；**没有证明它能从每次 fresh 的当前 Train 航段内到达，也没有在本次 Train 审计轨迹观察到负 C**。该边界不能冒充常见真实负成本数据。阻断严格倒数所需的零成本则已在当前 Train 真实动作中直接观测。

固定 SOC 的完整充放电检验：同 SOC 端点时其修正和为零，电池往返母线效率为 `.95^2=.9025`，实际氢气和退化仍只记一次。负单步等效成本或充电抵扣的参考价值含义，必须与物理能量创造及会计重复收费区分。
