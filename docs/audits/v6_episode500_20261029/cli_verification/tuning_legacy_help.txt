usage: tuning.py [-h] [--episode-search] --study-dir STUDY_DIR [--smoke]
                 [--trials TRIALS] [--train-steps TRAIN_STEPS]
                 [--learning-starts LEARNING_STARTS] [--eval-every EVAL_EVERY]
                 [--seed SEED] [--sampler-seed SAMPLER_SEED]
                 [--reward-mode {v6_energy_soc_ramp,zhou_economic_only}]
                 [--pruner {median,none}] [--resume]

Direct, sequential Optuna trials around the V6 MaskedDQN/environment. No work
starts on import. Formal budgets must be supplied explicitly; --smoke uses
only a few synthetic seconds. Test has no loading route in this module.

options:
  -h, --help            show this help message and exit
  --episode-search      use the shared economic episode runner; combine with
                        --help for its options
  --study-dir STUDY_DIR
  --smoke               one tiny synthetic trial; no formal data
  --trials TRIALS
  --train-steps TRAIN_STEPS
                        formal transition/Adam budget per trial, excluding
                        warmup
  --learning-starts LEARNING_STARTS
  --eval-every EVAL_EVERY
  --seed SEED
  --sampler-seed SAMPLER_SEED
  --reward-mode {v6_energy_soc_ramp,zhou_economic_only}
  --pruner {median,none}
  --resume
