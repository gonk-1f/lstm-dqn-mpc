# V6 正式八轮训练：Q 值、TD 拟合与动作排序分析

本报告仅分析 run02 已保存的正式 Train、Greedy Validation 和 checkpoint 诊断记录，未启动训练、网络推断、环境回放或新实验，未读取 Test。run02 配置为普通 DQN、单步 TD、学习率 0.0001、SOC 权重 0.2、FC 波动权重 0.05，动作保持 13 档实际增量 −60～+60 kW。

主要结论：网络的失败终止 Q 值逐渐变负，说明失败价值有被学习；但八轮结束时仍严重低估失败代价，正常终止价值也未准确拟合。固定状态动作排序发生明显反复，实际第八轮低 SOC 轨迹仍会选择保持极低 FC 或降低 FC。失败终止 MAE 下降没有转化为稳定的 Greedy 控制改善，不能据此宣布收敛。

四类经验为普通非终止 `normal_nonterminal`、正常终止 `normal_terminal`、失败终止 `failure_terminal`、失败前缀 `failure_prefix`。训练 draw 统计包含重复抽样；在线 P95 在超过 8192 个 draw 后来自独立 reservoir 估计。下文表格使用 checkpoint 的只读 Replay 诊断：每类最多 8192 条不同经验，类别不足 8192 时全部测量。样本 P95 不能直接写成整个 Replay 的总体 P95。

带符号残差统一为 `TD target − Q_online(s, executed_action)`。负残差表示 Q 比当前目标更高。TD target 是当前 Target 网络产生的学习目标，**不是实际最优 Q 值 Q\***。原始探索轨迹的累计回报也是行为策略回报，不是反事实策略收益。

016 的最优与次优 Q 差只有 0.0393，表明动作选择十分接近；044 的错误保持排序却有约 5.15 的间隔。既存在接近并列时的排序不稳定，也存在对不合理保持动作相对明确的偏好，不能统一解释为“Q 值几乎一样”。

## 6. 奖励尺度、Huber 损失与稀少终止经验

源码 `src/v4/dqn.py::DirectPowerDQN.learn` 使用 Uniform Replay、batch size 64、`smooth_l1_loss(q, target, beta=1)` 和梯度裁剪 10；实际 TD 目标由 `masked_dqn_targets` 计算，终止经验不 bootstrap。这里没有发现“失败终止仍继续 bootstrap”的证据。

第八轮实际训练 312007 次 Adam 更新，共 19968448 个 minibatch draw，其中失败终止仅 558 个，约占 **0.00279%**。大幅失败惩罚约 10132.66，而普通即时奖励量级小得多。Huber beta=1 时，绝对 TD 误差超过 1 的单样本损失对 Q 的导数幅值饱和为 1；误差达到数千，不会使该样本对平均梯度的直接系数也扩大数千倍。网络 Jacobian、样本状态和批次内梯度抵消仍会影响最终参数梯度。

因此，“失败惩罚很大”不等于“失败终止样本在参数更新中具有足够影响”。罕见终止抽样与 Huber 饱和，有源码和实际 draw 比例支持，能够解释为什么巨大的终止残差会长期保留。但本次没有做因果消融，不能把它宣布为唯一根因，也不能据此直接断言更高学习率、更多轮次或更频繁 Target 复制就能修复。

同样，后期正常终止 Q 明显偏正、固定排序反复、Greedy FC 频繁变载，都提示需要检查共享网络和 bootstrap 价值估计的稳定性。仅凭这些结果还不能将问题精确归为某一种最大值高估机制，更不能把改用复杂算法作为已经验证的修复。

## 7. 下一版优先事项

1. **先处理一步合法但下一步不可恢复的问题。** 当前合法动作集合只检查本秒物理约束，实际第八轮失败前一秒仍可能全档合法，下一秒所需 FC 却已超出 ±60 kW。优先审视 `src/v4/control.py::_v6_feasible_fc_actions` 与 `src/v4/actions.py` 的候选动作交集，使 SOC 安全余量和增量可达性进入下一步恢复条件。具体保守程度仍需基于现有仿真假设设计，不能声称已标定实船爬坡能力。
2. **针对终止价值约束不足，先统一审视奖励/TD 尺度与有效梯度权重。** 重点是每秒奖励、约一万的单次失败惩罚、Huber beta=1、Uniform Replay 下终止抽样比例之间的关系。需要形成明确的数值方案后再实施；本报告没有修改损失、奖励、采样、学习率、网络或训练预算，也不建议凭本次 MAE 趋势直接扩大训练。

现有资料支持“完整 DQN 确实训练，但所得策略尚未稳定学会 SOC 维持与可恢复动作选择”的结论。当前 checkpoint 和第八轮结果应作为分析对象保存，不能把最后一轮自动视为最佳策略。
