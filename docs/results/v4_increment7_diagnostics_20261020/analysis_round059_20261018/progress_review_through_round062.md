## 4. 价值拟合与收敛

- 当轮采样总体TD MAE由R1的0.641958降至R62的0.080170，单位为缩放后的训练奖励。
- R62未加权Huber均值0.02448287、PER加权Loss0.000006058、平均IS权重0.00090177。加权Loss很小不能当成Q值已准确。
- R62普通非终止TD MAE0.05878、失败前缀0.25401、正常终止0.32168、失败终止0.20174。困难类别误差仍明显高于普通经验；这些不是固定留出集误差。
- 第59→60轮Greedy性能变化不来自评价时随机探索，因为epsilon始终为0；现有报告不能进一步量化目标漂移、共享网络拟合干扰、状态信息不足的各自贡献。
