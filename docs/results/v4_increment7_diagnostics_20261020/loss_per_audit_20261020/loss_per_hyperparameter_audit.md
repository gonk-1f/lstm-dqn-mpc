## 3. 损失、目标和梯度链条

令`delta=y−Q_online(s,a)`：

```
a_next = argmax_{a in legal_next} Q_online(next_state,a)
y = r_scaled + (1-done)*Q_target(next_state,a_next)  # gamma=1,n=1
l(delta) = 0.5*delta^2, abs(delta)<1
           abs(delta)-0.5, otherwise
L = mean_i(w_i*l_i)
```

|检查|实际代码|判断|
|---|---|---|
|损失|`src/v4/dqn.py:505–509`，uniform调用默认`reduction='mean'`；PER调用`reduction='none'`后乘[B,1]的IS再mean|正确；不是先平均loss再乘平均IS，也不是`sum(w*l)/sum(w)`|
|阈值|functional smooth_l1_loss未传beta，采用默认1|与HuberLoss(delta=1)等价；一般beta≠1时SmoothL1=Huber/beta，不能混用|
|TD符号|`:519`保存`target-q`；loss对称，priority取abs|一致，未把符号倒置当作下降方向|
|动作选择/估值|`:33–53` Online合法argmax，Target gather同一索引|标准Masked Double-DQN，不是Target自己选动作|
|mask|`:490–500`从Replay下一增量索引构造布尔mask；非终止空mask抛错|正确；不以非法动作估值，不自动回退绝对动作|
|终止|`torch.where(done==0, continuation,0)`|真实正常/失败终止均不bootstrap；正常终止的空mask不计为空可行域失败|
|梯度隔离|`:497–503`完整target构建处于`torch.no_grad()`|target及next Online均不反传；只回传当前Q(s,a)|
|反传与Adam|`:512–517` zero_grad→backward→clip_norm10→Adam.step→计数+1→soft_update|顺序正确；Adam只注册Online参数|
|Target|`:853–857` no_grad下`target.lerp_(online,tau)`|每次成功Adam更新一次；初始化完整复制一次；当前MLP无动态BN等buffer问题|
|priority刷新|`:520–530`用本batch**更新前**未加权abs(target-q)；重复ID合并取最大后刷新|常见合法实现；并非乘IS或Huber值作为priority。不是更新后的最新网络TD，存在正常滞后|

## 4. PER概率、固定失败配额与权重

`src/v4/prioritized_replay.py:63–132`：

```
p_i = (abs(delta_i)+1e-6)^0.6
P(i) = p_i/sum_j p_j
C = max_j (N*P(j))^(-beta_IS)   # beta_IS=1
w_i = (N*P(i))^(-beta_IS)/C
```

SumTree保存mass之和、MinTree保存有效最小mass；被移除槽位mass=0、min=inf，不会把空槽最小概率当作0。新经验以历史最大raw priority初始化。普通PER有放回，重复抽样合法；同ID在batch里仍有多份loss，刷新只取一次最大absTD。

**这里有固定配额，不是整个Replay的纯PER：** `dqn.py:689–719`通常先从失败终止池均匀无放回取2条，另62条从非失败终止池做PER。此时N只含非失败终止池299790条，失败池210条。

失败样本权重为`1/C`，普通样本按上述公式。beta_IS=1时，加权期望恢复的是“2/64失败均匀+62/64普通均匀”的既有配额目标，并整体乘`1/C`，**不是恢复30万池全均匀目标**。两类共用同一个C，未错误地给失败权重1而普通乘极小数。池不足时配额有原有回退规则，不能把每个warm-up batch都当作固定2/62。

本次从真实最终checkpoint重算：最小raw priority=1.490116e-7；加epsilon后再乘方，最小条件概率3.391502e-9；C=983.537289。这是极低TD priority与当前池分布造成的有限全局归一化，未发现MinTree空槽或除零错误。旧priority与当前absTD相关系数约.1205，说明优先级滞后值得观察，不是计算式错误的证明。

### MSE的解释陷阱

在当前99.4873%二次段样本上，标准MSE恰为SmoothL1的**2倍**；较大残差处MSE导数随absTD增长，Huber导数限幅。把MSE除2可成为另一个控制整体系数的诊断，但不能未声明就加入第三臂，也不能把它与标准MSE混报。此两臂本来就同时改变损失形状与其自然梯度尺度，应完整记录，Adam并非严格尺度不变。

失败尾部/高priority可能被MSE更强调，也可能增加共享拟合干扰。两者均为待验证假设，不承诺能消除振荡。

2. 梯度范数/裁剪触发率、逐次真实Adam位移及相对位移；Q范围、合法最优−次优/最优−保持差；Online/Target动作优势差。
3. 固定Train35/Validation8完整供电率、失败类型与位置；同一共同完成样本集合Zhou总成本及分项，未完整不得用截断低成本取胜。
4. SOC轨迹/边界停留、平均绝对FC变载、±60次数及反向次数。动作上限60，>100/200计数为0不是平稳性证据。
5. MSE仅使少数大TD变小、但普通经验/完成率/成本/变载恶化，或收益来自更大预算，则不支持更换；若各类和闭环共同改善且多seed复现，才支持升级。

**最终决定：当前保留SmoothL1(beta=1)与PER；不把改为同参数Huber当实验，不立即上MSE，不同时改学习率、tau和UTD。**
