# 船舶能量管理项目进度说明：供 GPT 分析

核查日期：2026-10-14，Asia/Shanghai。本文根据现存源码、Git 历史、训练报告和诊断附件整理，可将全文直接提供给 GPT。数值均说明版本、样本集合与单位；没有在本次整理中开展正式训练或打开 Test 轨迹。

## 1. 项目目的与目前结论

项目研究船舶燃料电池（FC）与锂电池的功率分配：在满足负载、电池功率和 SOC 硬边界的前提下，降低氢耗、燃料电池退化、电池退化和岸电购电四项模型经济费用，并观察 FC 变载、启停及电池能量储备。

原始研究路线是 **LSTM 预测负载 → DQN 调整 MPC 权重 → MPC 滚动优化 FC/电池分配**。项目已经分别实现了预测模块、多时间尺度加权 MPC、经济 MPC，随后转向 **每 30 s 直接输出 FC 功率的 MLP Double-DQN（v4）**。当前训练主线没有加载 LSTM，也没有进行 MPC 在线优化；仍复用 `EconomicMPC` 类里的物理模型和经济记账接口。

截至本次核查：

- LSTM 已做历史训练和评估，但五步 Validation WAPE 没有优于 persistence（保持当前负载）基线。
- MPC 已实现并做过尺度审计、Train 筛选与小规模闭环实验；不能称为完整三算法联合方案已成功。
- 最新 DDQN B 组完成 100 轮，末轮固定完整集合 **Train 17/21、Validation 6/7**；没有任何合格最佳模型，未进入最终 Test。
- B 组相比旧 A 组末轮完成数提高，但相同完成样本集合的费用增加，策略仍有 SOC 耗尽、FC 大跳变、高 SOC 停留及正常终止价值拟合问题。
- PER 是独立候选；DDPG/TD3 已有本地实现与合成核验记录，尚无正式训练效果。

### 3.2 功率、SOC 与经济模型

每个 ONBOARD 控制步：

```text
P_battery_bus = P_load - P_FC
电池功率为正：放电；为负：充电。
放电时电池侧消耗功率 = P_battery_bus / 0.95
充电时电池侧功率 = P_battery_bus × 0.95
SOC_next = SOC - 电池侧功率 × (30 / 3600) / 624
```

FC 效率采用外部 100 kW 特性曲线，按同负载率映射到 600 kW，并插值；不是固定效率，也不是实船 8 × 70 kW 标定。氢低热值采用 120 MJ/kg。FC 退化包含低/高载运行、变载及启动循环；电池退化采用 SOC/电流加权 Ah 吞吐。

| 冻结经济 / 寿命参数 | 值 |
|---|---:|
| 氢价 | 21.9 元/kg |
| FC 单位设备价值 | 3500 元/kW |
| FC 替换价值比例 | 0.5，总替换价值 105 万元 |
| 电池单位设备价值 | 2000 元/kWh，总替换价值 124.8 万元 |
| 岸电价 | 1.10 元/kWh，峰价情景，非实测码头电价 |
| FC 低 / 高载运行损耗系数 | 10.17 / 11.74 μV/h |
| FC 变载损耗系数 | 0.0441 μV/参考单元 ΔkW；聚合功率映射为 1/6 |
| FC 启动循环损耗 / EOL 损失 | 23.91 / 70000 μV |
| 电池额定 Ah / 寿命归一化吞吐 | 1444.44 Ah / 15000 × 额定 Ah |

在未到 EOL 时，FC 单次 0→正功率的启动循环分项费用为 **358.65 元**；启动区间还可能有氢耗、变载及运行费用。正→0 不另记第二次完整启动循环，但会计变载。模型系数与寿命归一化不是实船寿命试验结果。

实际模型费用账本始终只有：

```text
C = C_H2 + C_FC_degradation + C_battery_degradation + C_shore_electricity
```

SOC 辅助项、失败训练惩罚和奖励缩放不属于上述人民币费用，不能与账本重复相加。

### 3.3 当前物理边界与岸电假设

DDQN 物理 mask 检查当前已观测负载下的电池功率与下一步 SOC。它保证单步合法，**不保证未来完整航段可行**。当前主线没有 FC 最小稳定出力、爬坡率、最短开停驻留或启动时长的硬约束；10 kW 只是离散动作间隔。旧配置中的 48 kW/s、1 s 步长、6 步预测、SOC reference 0.55 不属于当前 v4 生效配置。

当前主线已经删除 Scheme A 人工停机候选门控：全部物理可行动作均可被选择，包括 0 kW。不能沿用旧实验“所有零功率均由 mask 强迫”的结论解释新 B 组。

已确认 SHORE 使用**模型化固定目标 SOC 0.6 补能**。原始电池功率只保留来源，不决定补能量；计算不受记录靠港时长限制。SOC≥0.6 不补能，也不将多余电量变现。FC 关闭并记账，计算中的充电积分步不是实测充电轨迹。没有后续 SHORE 且末端 SOC<0.6 时，另作终端补能费用估值，不改变实际末端 SOC。现有终端估值先将 FC 历史置零，未核算该终端边界的 FC 停机变载；中途 SHORE 停机变载已计入。经济评价依赖这些冻结情景，不能解释为实测岸电账单或全部真实运营费用。

依据：`src/v2/config.py`、`src/v2/models/`、`src/v2/economics.py`、`src/v3/control.py`；当前主线 `src/v4/control.py`。

## 4. 数据与评价口径

正式数据和侧车共有 **43 个 parent：Train 30、Validation 8、Test 5**；当前 30 s 侧车行数分别为 23590、4623、2765。不能把别的历史数据集或子航段数当作当前 Test 数量。

数据来源是 8 个 FC 功率通道与 12 个 BMS 电压/电流簇，负载以源侧功率平衡派生：`P_load = P_FC + P_battery_bus`，不是独立负载表测量。原始电池符号与控制母线符号相反。数据经过通道对齐、质量检查、插值和零边界划分；当前使用冻结的主数据、AIS 侧车与 v3 工况标签。

v3 标签把原来部分 SHORE 重判为 ONBOARD 或 UNKNOWN。模型岸电确认条件包括 FC≤1 kW、电池<−1 kW、航速≤0.1 kn、有效数据及连续至少三个 30 s 点；前两点为 pending。该标签表示模型补能机会，不能证明实际接入电网。

- Train 有 9/30 个样本含 UNKNOWN，固定完整可评价集合为 **21**。
- Validation 有 1/8 个样本含 UNKNOWN，固定完整可评价集合为 **7**。
- 每轮都进行 ε=0 的 Greedy Train 与 Validation，Validation 不再由 Train 全完成触发。
- UNKNOWN 是缺失观测截断，不计成功或供电失败，不制造终端补能、失败罚款或虚构后继。
- 当前 `observed_nstep` 只保留 UNKNOWN 前完整 8 步奖励及真实后继均已观测的非终止窗口；最后缺少后继的尾窗舍弃。结果标记 unresolved，不冒充成功经验。
- 合格模型要求 Train21、Validation7 的固定完整集合全完成，含 UNKNOWN 样本的已观测前缀没有物理失败，且无程序执行错误；之后按固定 Validation 集合完整费用选优。

当前 DDQN 正式训练与选模没有打开 Test，已归档运行记录为 `test_payloads_opened=0`。**但历史 LSTM 曾做过冻结预测器的 Test 诊断**，因此不能笼统声称“整个项目从未看过 Test”。后续研究应说明已知历史诊断与最终盲测的边界。

## 5. LSTM、MPC、DQN 各自进程

### 5.1 LSTM：实现和训练已有，预测收益未成立

实现位于 `src/v3/forecasting.py`，没有独立的当前 `src/lstm` 目录。输入为过去负载，历史候选 H=6/12/24，对应 3/6/12 分钟；输出未来 5 点、150 s。H24 输入 `[batch,24,1]`，单层 LSTM hidden32，加线性五输出头，输出是最后观测负载加残差。只使用同一样本内连续 ONBOARD 窗口，未输入 AIS/航速。

历史训练：seed42、Adam0.001、batch256、归一化 Smooth L1、最多20 epochs、patience4；归一化参数只在 Train 拟合。H24 有 16690 个 Train 窗口；三种历史长度在相同 2683 个 Validation 起点比较。

| 五步 Validation 预测器 | WAPE | MAE / kW | RMSE / kW |
|---|---:|---:|---:|
| Persistence | 10.470354% | 35.680565 | 86.155479 |
| LSTM H6 | 10.764535% | 36.683066 | 85.026374 |
| LSTM H12 | 10.864536% | 37.023846 | 84.939385 |
| LSTM H24 | 10.719972% | 36.531205 | 85.116453 |

H24 仅在 LSTM 候选中 WAPE 最好；相对 persistence 的 WAPE skill 为 **−2.384041%**。部分 RMSE 降低不足以证明整体预测或闭环经济收益。历史 Test 预测诊断还显示一步变化约 30 s 的相位滞后；不是已验证的控制收益。当前 v4 不启用此预测器。

依据：`docs/history/v3/v3_predictive_control.md`；历史提交 `2e70008` 的 `outputs/v3_lstm/selection.json` 和预测诊断。历史输出已不在当前活动分支的普通目录中。

### 5.2 MPC：两个阶段已实现，但作用及未完成项不同

| 路线 | 已实现内容 | 主要证据与局限 |
|---|---|---|
| v2 多时间尺度加权 MPC | Ts30 s、N5、DQN 权重保持 M5、LPF τ180 s；跟踪、FC 差分平滑、SOC 0.4–0.6 死区三项控制目标；SLSQP | 经济费用作为上层实际奖励，不能称为经济目标直接优化；历史共同29条 Train 上 DQN M5 费用101861.81元，原固定基准102232.22元，仅低约0.362%；另一个固定权重101495.48元更低。各策略都未完成 `_015`，属于 Train 内证据 |
| v3 经济 MPC | Ts30 s、N5、每步调整两项权重；曾接 LSTM，后用 persistence；SLSQP 优化经济代理、LPF 参考及 SOC 中心项 | Train 标定 Cnom≈8.927633元、16动作候选；两段 Train×16动作共32次短程回放全完成，尚未形成完整 v3 DQN 训练/Validation 最优策略 |
| 当前 v4 | 复用物理、退化、岸电及费用账本 | 不调用 MPC 在线求解，不使用上述预测窗口或 LPF |

v2 的 N5 表示优化预测 150 s，M5 表示同一权重实际保持 5 次滚动求解；不能因为数值相等就混淆。v3 经济代理遗漏实际账本的非连续启动费，曾出现 0.23–3.70 kW 微功率反复跨零：某短段 6 次启动费用2298.20元，而另一候选1次启动费用513.59元。32次 pilot 合计耗时约1008 s。这些是代理与账本不一致、计算开销的具体问题，不证明 MPC 已经解决完整项目。

依据：`docs/history/v2/method_v2_multiscale_dqn_wmpc.md`、`v2_rl_mpc_literature_and_train_ablation_2026-10-05.md`；`docs/history/v3/v3_persistence_dqn_mpc.md`。

### 5.3 当前 v4 DDQN：直接功率分配

当前 7 维因果状态为：

```text
[SOC,
 上一步FC/600,
 上一步FC差分/600,
 更前一步FC差分/600,
 当前负载/600,
 当前负载差分/600,
 上一步负载差分/600]
```

FC 历史是实际执行命令；当前负载在决策前观测。没有未来负载、剩余真实行数或离线终点信息。旧 8 维的累计退化比例、出港标志已移除，独立 Outcome 网络也已删除。

| 当前正式入口参数 | 值 |
|---|---|
| 网络 | ReLU MLP，7–128–128–61 |
| 动作 | FC 0:10:600 kW，共61档；电池承担差额 |
| 算法 / 更新 | 带物理 mask 的 Double-DQN，online 选后继动作，target 估值 |
| γ / n-step | 1 / 8；同一样本确认 SHORE 前后可连续，不能跨 UNKNOWN 或不同样本 |
| Adam / batch | 0.001 / 64 |
| Replay | FIFO300000；每新增32条经济经验获得1次更新额度 |
| 采样 | 失败终止配额2，其余普通池均匀；不是 PER，也不是完全全池均匀 |
| Target | 初始化硬复制1次，每次经济优化后 τ0.001 软更新 |
| Loss / clip | Smooth L1 δ1 / 梯度范数上限10 |
| ε / seed | 第1轮1，第70轮0.05，第71–100轮保持0.05；Greedy0；seed42 |
| 奖励缩放 | 最终组成的原奖励进入经济 Replay 时统一乘0.001一次 |

共同 Train13 的 FC 平均功率225.65→259.98 kW、平均绝对变载32.26→38.03 kW；共同 Validation5 对应210.86→244.45 kW、22.39→33.60 kW。新增完成样本没有混入这个比较。**B末轮完成数更高，但共同完成集合的费用和平稳性没有同步改善。**这也是历史版本间的描述性比较，不能量化为 isolated replay 修复的因果效应。

## 7. DQN 遇到的问题：事实、解释边界与已做诊断

### 7.1 长期可行性没有被一步 mask 保证

B100 Train `_008/_015/_044/_050` 和 Validation `_036` 均 SOC受限失败；结构性总功率不足和程序执行错误为0。`_015` 最后7步FC仅40 kW，而负载约1095–1105 kW，电池持续承担约1055–1065 kW，SOC降至0.20036；下一步无合法动作。之前600 kW仍合法，且实际保存的Train逐动作Q显示40 kW被排在600 kW前面。

这可以确认是策略选择与能量储备下降相连，不能从“最后一步600可行”推断此时还能救回全程。旧 A 的 `_036` 有完整物理可行性见证，但归档策略早在第20行已丧失余程可行性；最后8/32步才改高FC也救不回来。该见证不能直接当成新B同一失败时刻的反事实。

### 7.2 正常终止价值拟合明显不足

B100实际399次更新中的统计：整体TD MAE0.30257，失败终止0.17558，正常终止窗口 **4.54357**。正常终止262个抽样位置的Q均值−4.63904、目标均值−0.09546，全部绝对TD>1。单位是乘0.001后的训练奖励等值，不是人民币实际成本。

已核查路径未发现 Double-DQN选择/估值、n8累计、一次缩放或真正终止禁止bootstrap的公式错误。正常末端未来费用小、目标接近0本身并不错误。问题包括采样与共享函数拟合，而不能仅说“惩罚没算”“梯度爆炸”。

最新B冻结诊断中，一对相近7维状态、同70 kW动作，正常末端与中途参考目标约−0.03403/−5.89193，当前Q却约−5.72072/−5.71462；局部Huber梯度cosine约−0.9999994。32对里仅10对梯度负内积，不能把所有状态都判为冲突。它支持具体的共享拟合干扰与任务阶段信息不足疑问，但不是唯一根因证明。

### 7.3 UNKNOWN 经验覆盖缺口已修复，仍未解决策略

旧 A 连同预填充丢弃520554个已执行前缀决策。新 B 将可信完整窗口保留，且增加Replay覆盖/来源/抽取诊断；末轮仍失败。下一步需要区分经验不足、同动作不同状态的拟合干扰、未执行动作Q的泛化与任务语义，不能再把一切归于“失败经验完全没有学习”。

### 7.4 FC 大跳变由 Q 排序引起，已有变载费用未阻止它

B100 `_002` 完成405步，但有52次内部FC跳变>300 kW；低且几乎不变的负载下也有42次此类跳变。例如负载约78 kW时FC20→520→70 kW，原功率仍物理可行，Greedy网络参数固定。实际Q排名变化使大幅动作被选中，不能解释为 MPC改动作或mask强迫。

只把其中第160步520改为20，之后保持原归档FC序列的独立物理反事实，仍完成405步；四项费用降低98.86元，含SOC辅助项的总原奖励改善33.91单位。它证明有更好且可行的同负载动作序列，不证明真实最优Q的唯一排序，也不是可直接部署的动作覆盖规则。

### 7.5 高 SOC 与低 SOC 失败并存

B100 `_006` 的233/351步SOC≥0.79，末端0.79917；SOC辅助项确实已计入。该例3个FC零动作仍有正功率合法，是自主选择，不能套用旧实验受迫停机解释。另一方面，高SOC也会使原较大FC动作不合法，部分降功率确实受物理上界限制。B100 Train全部已执行步高SOC占34.54%，后10轮41.80%。平均SOC不足以说明能量管理合理。

### 7.6 没有数值爆炸证据，也没有策略收敛证据

B100平均/最大梯度范数约0.69985/1.33416，399次更新裁剪0；全100轮最大范数约1.98876，没有触发clip10。Q值范围有限。低整体loss、失败末端TD下降和没有梯度爆炸，均不能替代完整完成率、同集合费用、变载及SOC诊断。
