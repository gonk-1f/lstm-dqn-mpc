# v4 正式训练前 TD 数值诊断（2026-10-08）

基于 `d111c99` 原始生产算法。只使用固定合成经验；不读取正式Train/Validation/Test轨迹，不启动正式训练，不改变默认缩放1、物理模型、经济账本或训练超参数。

## 对照契约

比较统一奖励乘数1、0.01、0.001。正式账本保留人民币原值，缩放仅作用于进入经济TD的训练奖励，包括实际经济奖励、SOC shaping、奖励重分配、正常终端补能及失败惩罚。
相同61分支、seed42、MLP8–128–64–61、Adam1e-4、batch64、γ1、n1、replay32、target500、clip10、SmoothL1 beta1。
全部61首动作共享同一状态；0/10/20/30kW导致后续SOC受限，其余57分支可完成固定后续轨迹。
先用原奖励复现既有受控Q排序测试，再对当前默认重分配模式完成同预算三组缩放对照。每个模式内部只改变alpha；主结论按当前默认重分配模式报告。
该fixture不是正式负载分布，失败分支人为重复16次用于压力验证；FC0初始bias加1只作用于诊断实例。

## 误差与梯度解释

失败终止target为含一次失败惩罚的reward，无bootstrap。非终止仍用原始masked Double-DQN。
原生TD误差/alpha用于换回原奖励单位；再除固定C_fail得到跨缩放共同尺度的无量纲误差。不能只看原生loss随alpha变小。
SmoothL1 beta1在绝对误差大于1时导数饱和，不因残差约一万元就自动产生一万元梯度。裁剪前范数和触发率必须实际测量。
固定Huber阈值、Adam epsilon、裁剪阈值和未缩放初始bias使优化过程不具严格缩放不变性；正乘数的目标排序等价不代表有限预算的学习轨迹相同。
只有合成结果，不把TD MAE或某个小样本的动作变化解释为正式训练发散或已改善正式完成率。

## 奖励与失败惩罚尺度

固定合成数据（未缩放）：

| 项目 | 原奖励中位数绝对值 | 重分配中位数绝对值 |
|---|---:|---:|
| 普通非终止 reward | 238.621573 | 243.496919 |
| 正常 terminal reward | 484.825923 | 477.919182 |
| 失败 terminal reward | 10516.370473 | 10516.370473 |
| 成功完整段 return | 961.570079 | 961.570079 |

C_fail=10132.6601，比合成普通单步中位数约大42.46倍（重分配约41.61倍），比3步完整段return约大10.54倍。
但冻结的30个历史Train完整**样本经济成本**中位数为5180.827749，C_fail约为其1.96倍，处于该费用集合P95量级。
历史“样本经济成本”不等于单个ONBOARD段或带SOC shaping的完整训练return；本次未读取正式轨迹以重建该return分布。
因此可说惩罚相对普通单步明显大，不能据此断言其相对全部正式航段return过大或足以保证完成。

在alpha0.001下普通reward中位数约0.24、失败惩罚10.13，幅度与初始Q及固定Huber阈值更接近；实际账本费用不缩放。

## 建议与限制

**建议下一次正式训练以全奖励统一alpha=0.001作为数值起始配置，而不是继续未缩放的训练单位。**
依据是相同预算/采样下两种奖励模式均改善原单位TD拟合、消除本fixture的裁剪触发，普通单步更接近Huber二次区。
这是数值尺度建议，尚非经济性/正式完成率的推荐证据。本次正式默认仍为1，没有接入缩放或启动训练；需后续授权单变量对照才改变运行配置。
正式报告继续使用原人民币账本，Q/reward/TD日志同时标明缩放单位和除alpha后的值。不能只缩放H2或只缩放失败惩罚。

后续最小验证应在完全相同失败协议、CF倍率1、seed42、beta500、replay32、target500、gamma1/n1和探索进度下比较alpha1/0.001；原/重分配两臂也应采用一致倍率，避免同时调整reward和failure权重。
每轮完整greedyTrain/Validation资格门槛不变，Test继续封存；本次不执行该计划。

限制：只有1个初始低SOC场景、固定后续动作、seed42和602更新；初始FC0 bias+1未缩放，可能影响不同alpha的早期路径。无长期SOC分布、正式收敛、优于基线或成本优势结论。
独立测试曾发生一次并发PyTorch导入的Windows原生访问异常，现有记录不足以确定根因；最终全部验证串行通过。这不是正式训练失败或TD发散证据。
