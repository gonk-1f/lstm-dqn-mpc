# v4 直接功率 Double-DQN：进度、参数与未解决问题（2026-10-07）

本文记录 `feat/direct-power-mlp-ddqn` 分支的**当前代码**及单种子实验。下文 40 轮结果是在引入 SOC 软惩罚**之前**得到的 `beta_soc=0` 基线；新的 SOC 惩罚仅完成了 5 轮筛选，不能将其当作 40 轮稳定性结果。v2 的 DQN 调 MPC 权重、v3 的持续预测/LPF、LSTM 和 KAN 均不在当前 v4 控制链中。旧版本文档中的 `N=5`、`M=5`、36 动作和 MPC 权重不是本版本的训练参数。详细实现见 [v4 方法说明](v4_direct_power.md) 和 [历史失败审核](v4_training_failure_audit_2026-10-06.md)。

## 当前控制链与数据

每个 30 s `ONBOARD` 区间先读取**当前**实测负载，再由 MLP Double-DQN 选 FC 功率 `0, 10, ..., 600 kW`（61 个离散动作），电池母线功率为 `P_bat=P_load-P_FC`。一阶段动作掩码排除超出电池功率或 SOC 界限的选择；它不保证以后几步仍有可行供电动作。v4 不预测未来负载，不求解 MPC，也不用 LPF；`EconomicMPC` 类只提供已存在的单步物理/经济核算。无动作后的功率不被裁剪或虚构。

控制状态的 8 个标量依次为：SOC；当前负载/600；当前与上一负载差/600；上一与再上一负载差/600；上一 FC 功率/600；FC 累计经济寿命消耗比例；电池累计经济寿命消耗比例；出港标记。出港时负载历史和上一 FC 命令以 0 为控制边界，首步执行的仍是实测负载。样本默认初始 SOC 为 0.6。样本内部经过岸电后，下一次出港继承实际充到的 SOC。

工况由数据中的 `operating_mode` 给定。`SHORE_PENDING/SHORE_CHARGING` 无 DQN 动作、FC 为 0；负的电池母线功率是充电请求，接受量受电池充电功率与 SOC 0.6 上限约束。实际接受量更新 SOC、电池退化和购电费用。岸电紧随航段时，该岸电块成本计入前一 ONBOARD 终止 transition 一次；下一出港开始新的决策序列。FC 停机变载与下次启动均通过原 FC 退化模型核算，无独立停机收费项。

正式数据 manifest 为 Train/Validation/Test = **30/8/5** 个样本，Train 有 **23,590** 个 30 s 物理区间。训练入口只加载 Train、Validation；已核实的训练报告中 `test_payloads_opened=0`。最终 Test 读取时要求原始负载序列首尾为 0 kW；原始末尾 0 kW 是**不执行的边界行**。Train/Validation 最后一个可执行行均为 ONBOARD，不能由这个边界行推定已发生岸电补能。

## 当前 DQN 训练配置

| 参数 | 当前值或语义 |
| --- | --- |
| 网络 | 经济 Q：8 输入 → ReLU 128 → ReLU 64 → 61 个 Q 值；在线/目标网络。另有同宽度诊断性完成结果网络，不参与选动作 |
| 算法 | 可行动作掩码 Double-DQN；Smooth L1 TD loss；Adam |
| 折扣、学习率 | `gamma=1.0`；`1e-4` |
| 回放、批量 | FIFO 容量 100,000 条；batch 64；均匀随机采样 |
| 梯度 | 范数裁剪 10；经济 Q 每**完成**一个训练样本更新 16 次；每轮同步目标网络。完成结果网络对成功和无动作失败样本各尝试 16 次更新 |
| 预填充 | 用当前负载跟随策略生成可完成轨迹，随后每完成样本再进行 16 次预训练更新 |
| 探索 | 每轮固定 ε，跨 40 轮线性下降；原默认 `0.15→0.02`，对照 `1.0→0.05`；验证 ε=0 |
| 随机种子 | 对照实验均为 42；没有多种子稳定性结论 |
| 输出 | 每 50 个已选择 ONBOARD 动作打印一次；这一计数不是梯度更新数 |

训练中一旦出现下一状态无可行动作，已执行前缀的状态、动作、实际人民币回报和观察到的失败标签进入**独立**的完成结果回放。若同一样本先前有已结束的岸电前航段，这些已完成航段标成成功并保留在经济 Q 回放；只把末尾未完成航段标成失败。未完成航段不进入经济 Q 回放，避免把“少付后续成本”的失败当成经济上便宜的正常终止。完成结果网络只预测采样策略下观察到的失败关联，不能证明每个前缀动作均导致失败，**目前不参与动作选择，因而不能声称经济 Q 已学会规避失败**。没有虚构的 CNY 失败罚款。最终贪婪策略必须完整跑完 Train 30/30 和 Validation 8/8 才有资格保存正式 `selected_agent.pt`；训练过程的探索失败只记录和学习，不中断其余样本。`outputs/v4_direct_power*/` 是本地忽略目录。

## 当前物理与经济参数

这些是代码采用的**研究仿真方案**，不是实船测量参数；旧文档中的真实船舶规格也不是当前 `PlantConfig.research_simulation()` 的输入。

| 模型 | 生效参数与算法 |
| --- | --- |
| 功率与能量 | FC 额定 600 kW；电池额定 624 kWh；电池母线充电下限 -624 kW、放电上限 1,248 kW；`P_bat>0` 为放电 |
| SOC | 航行硬界限 0.2–0.8；默认起点 0.6；岸电接受目标最多 0.6 |
| 电池效率 | 充电 0.95，放电 0.95；航行 SOC 按母线功率与效率更新；岸电记录视作电池侧充电请求，购电量由接受的电池侧能量除以 0.95 |
| FC 氢耗 | FC 效率用 `FC_Data.xlsx` 中 100 kW 参考曲线按相同负载率映射至 600 kW，经 PCHIP 插值；氢低位热值 120 MJ/kg（33.333… kWh/kg） |
| FC 退化 | 100 kW 参考单位的低/高负载运行损失 10.17/11.74 µV/h，高负载界线 0.8；变载 0.0441 µV/参考单位 ΔkW；启动周期 23.91 µV/次；600 kW 聚合功率映射比例 1/6；寿命终点 70,000 µV。停机变载由 `abs(ΔP)` 项记录，周期项在 0→正功率时计一次 |
| 电池退化 | 额定电压 432 V，额定电量 624 kWh；电流 `I=P_bat×1000/432`；每步以 `|I|Δt/3600` Ah 乘 SOC 应力 `1+3.25(1-SOC)^2` 和电流应力（放电 `1+0.45 I/I_1C`，充电 `1+0.55 |I|/I_1C`）；寿命归一化为 15,000 倍额定 Ah。该寿命因子属文献/项目假设 |

实际一步经济账本为

```text
C_observed = C_H2 + C_FC_deg + C_Bat_deg + C_shore_electricity
r_onboard = -(C_H2 + C_FC_deg + C_Bat_deg + beta_soc * phi(SOC_after))
phi(s) = (0.4-s)^2 if s<0.4; 0 if 0.4<=s<=0.6; (s-0.6)^2 if s>0.6
C_H2 = m_H2 * 21.9 CNY/kg
C_FC_deg = Δmin(D_FC, 1) * (600 kW * 3500 CNY/kW * 0.5)
C_Bat_deg = Δmin(D_Bat, 1) * (624 kWh * 2000 CNY/kWh)
C_shore_electricity = E_grid * 1.10 CNY/kWh
```

其中 `D_FC=累计单电池电压损失/70,000 µV`，`D_Bat=累计加权 Ah/(15,000×624,000/432 Ah)`。氢价 21.9 元/kg，设备价 FC 3500 元/kW、电池 2000 元/kWh，岸电电价 1.10 元/kWh；岸电价是情景值，非码头实测电价。岸充电池退化留在 `C_Bat_deg`，不再放进购电费用重复计数。FC 给电池充电造成的额外氢耗、FC 退化和电池充电退化已随物理功率结算。`beta_soc` 为非负可配置系数（默认 0），按动作执行后真实 SOC 计算，仅在 ONBOARD 决策步生效；SHORE 无此惩罚。它是训练目标中的软约束，**不属于实际发生的经济费用**，报告单列 `completed_soc_soft_penalty_cny`。没有另外增加 FC 跟踪/波动项、MPC 目标或失败 CNY 罚款，也不除以 `Cscale`。最后一步 ONBOARD 奖励另外包含紧随其后的实际岸电费用或以下模拟结算；不能遗漏这些既有账本项。

若样本末端没有实际 SHORE 且 `SOC_T<0.6`，最后一个 ONBOARD 奖励还减去**模拟末端结算** `C_terminal,grid + C_terminal,BatDeg`。其充电电量缺口为 `(0.6-SOC_T)×624 kWh`，网侧等效电量再除以充电效率 `0.95`；电池退化由现有岸充模型按电池侧最大 624 kW、末步截断至 SOC 0.6 的假设充电曲线计算。这个功率曲线是核算假设，因为只有末端 SOC 无法唯一确定充电退化。模拟结算不更新真实 SOC，不增加实际负荷行，不冒充实际岸电。已有实际 SHORE 时沿用实测请求与接受功率，**即使只充到低于 0.6 也不再补模拟账**。报告分别列出已观察费用和模拟费用；仅可比总费用相加。没有真实岸电且 SOC 不足时，可比总费用 = 已观察费用 + 模拟末端电网费用 + 模拟末端电池退化。

具体价格出处与证据等级见 [v2 经济参数](v2_economic_parameters.md)；本版本实际调用的常量在 `src/v2/economics.py`、`src/v2/models/` 和 `src/v3/control.py`。`EconomicMPC(nominal_cost_cny=1.0)` 只复用 `interval`/`shore_interval`，这个 `1.0` **不是** v4 奖励或成本的归一化尺度。

主要问题按证据区分：

1. **未来供电可行性**：掩码只检查当前一步。某些高负载航段在电池 SOC 被提前放到 0.2 附近后，即使 FC 输出 600 kW 也不能同时满足当前负载和 SOC 下限。它不是 600 kW 额定上限的实现错误。
2. **失败反馈尚未进入决策**：已执行失败前缀现已用于独立的结果分类训练，但该网络尚不改变 Q 动作或选模规则，当前经济控制策略的供电完成率改善仍未验证。不能把诊断分类器本身称为可行性保障。
3. **末端能量口径已有显式假设**：Train/Validation 的最后执行区间仍是 ONBOARD，随后没有实测岸电区间。现有模拟末端结算为此提供统一的 SOC 0.6 对照口径，但 624 kW 充电曲线和电价仍是研究假设，不能解释成发生过的交易。
4. **控制目标与可观测信息**：旧版纯经济奖励不会数学上保证“FC 平稳供基荷、电池削峰填谷”；新版只增加 SOC 工作区间软惩罚，不增加 FC 波动项。FC 退化已经计入变载。状态没有未来负载或航程信息；相同历史而未来高负载长度不同的航段，当前策略无法据此区分。

旧版全量重跑后完成率仍不足。下节先以相同数据、随机种子和训练配置筛选 SOC 软惩罚，再按**完整航段完成率、已观察费用、模拟末端费用、终端 SOC、FC/电池功率轨迹**评估。当前仍是 MLP Double-DQN 研究阶段。

### SOC 软惩罚：5 轮配对筛选

在完整 30 个 Train、8 个 Validation 上分别用 `beta_soc=0,250,1000,4000` 训练 5 轮；其余配置固定为 seed 42、ε=`1.0→0.05`、batch 64、每完成样本 16 次经济 Q 更新、每轮同步目标网络。每个候选值从同一随机种子重新初始化。系数单位为元：SOC=0.3 时四档每步惩罚分别为 0、2.5、10、40 元；SOC=0.2 时分别为 0、10、40、160 元。这是覆盖约一个数量级的初筛，**不是**系数已被优化或有统计稳定性的证明。Test 负载从未打开。

| β | 贪婪 Train 完成 | 贪婪 Validation 完成 | Validation 已完成样本经济成本/元 | Validation 模拟末端结算/元 | 已完成 Validation 最小 SOC | 已完成 Validation 平均终端 SOC |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 11/30 | 4/8 | 67,570.50 | 1,410.38 | 0.2000 | 0.2484 |
| 250 | **30/30** | **8/8** | **39,333.03** | 44.53 | 0.2310 | 0.7689 |
| 1000 | 20/30 | 6/8 | 17,137.14 | 293.39 | 0.2046 | 0.6440 |
| 4000 | 21/30 | 6/8 | 18,399.56 | 130.59 | 0.3429 | 0.7375 |

表中的经济费用是四项实际账本加必要的模拟末端结算，**不包括** SOC 软惩罚。只有 β=250 完整通过两套分割，其 Train 全样本可比经济成本为 **170,616.81 元**，Validation 为 **39,333.03 元**（实际 39,288.51 + 模拟 44.53）。其余 β 有失败样本，**完整分割经济成本未定义**，上表的完成样本费用不能直接比较策略优劣。将所有 β 均完成的相同 4 个 Validation 样本单独匹配比较，费用分别为 β=0：67,570.50、β=250：17,461.68、β=1000：10,831.89、β=4000：11,467.39 元；这是有限子集，不替代完成率门槛。

功率与 SOC 轨迹暴露一个重要限制：β=250 的已完成 Validation ONBOARD 步骤约 **95.8%** 位于 SOC>0.6，约 **73.3%** 位于 SOC>0.79；Train 约 **84.4%** 位于 SOC>0.79，平均终端 SOC 为 **0.7999**。这更像提前把电池充到硬上限以保留后续供电能力，并未实现设想的 `[0.4,0.6]` 工作区间。β=0 在 Validation 的 4 个失败样本为 `zero_boundary_010`、`019`、`036`、`047`；β=1000/4000 仍在 `010` 和 `036` 失败。Validation 八个样本的 FC、Battery、SOC 对照图和逐样本数据保存在 `outputs/v4_soc_beta_study_5r_seed42/`；例如 `zero_boundary_036_power_soc.png` 清楚呈现 β=0 提早耗到 SOC 下限、β=250 先高功率充电、其他两档后续仍失败的差异。

**结论限于单种子 5 轮筛选**：β=250 值得做一次完整 40 轮复核，重点看是否仍保持 30/30、8/8 以及是否持续贴近 SOC 0.8；不能据此宣布找到最优 β 或已经实现削峰填谷。40 轮期间不要用 Test 选参数。独立的结果网络仍不参与选动作，网络、动作、ε、γ 和更新频率在四组试验中均未修改。
